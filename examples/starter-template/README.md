# x402 LangChain Agent Starter

A developer template for building autonomous AI agents that use `@ihentrel/x402-scraper-langchain` to access paywalled web resources using Base mainnet USDC HTTP 402 micro-settlements.

## Setup

1. **Install Dependencies:**
   npm install

2. **Configure Environment Variables:**
   Create a `.env` file in this directory:
   OPENAI_API_KEY=your_openai_api_key

3. **Run the Agent:**
   npm start
